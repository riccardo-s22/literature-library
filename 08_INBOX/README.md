# 08_INBOX — Intake

Drop new citations, PDFs, links, datasets, protocols, and rough notes here.
For each item record the minimum (per `00_AGENT/MAINTENANCE_WORKFLOW.md` §1):
stable identifier or URL, date added, reason added, likely project/topic, source type.

Items leave the inbox once triaged and extracted into a canonical record under
`02_PAPERS/`, `03_DATASETS/`, or `04_METHODS/`. Do not build a full record from a
title or abstract alone when the source will influence a real decision.
